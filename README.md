# SpendWise

SpendWise is a free, offline expense tracker for Android, built with Kotlin and Jetpack Compose. It records income and expenses, keeps notes on transactions, sets reminders with due dates, and will include analytics for spending trends.

All data stays on your device. There is no sign-up, no bank linking, and no advertising.

## Download

Get the latest APK from the [SpendWise website](https://spendwise-application.netlify.app) or from the [`downloads`](downloads/) folder in this repository.

Version 0.3 requires Android 8.0 (API 26) or newer.

## Installing the APK

1. Download `SpendWise.apk` to your phone.
2. Open the file. If prompted, allow installs from your browser in Settings.
3. Open SpendWise. The app starts empty, so add your own income, expenses, and reminders.

## Features

- Add, edit, and delete income and expense transactions
- Search and filter by title, category, or note
- Transaction type tags and colored bars for quick reading
- Home screen with total balance, spending summary, and latest entry
- Reminders with due dates that remove themselves once they pass

**In development:** notes, analytics dashboard, CSV export, and local storage with Room.

## Project structure

- `index.html`: the website, with feature visuals, download section, and reviews
- `downloads/SpendWise.apk`: the current release build
- `.gitignore`: keeps signing keys and build files out of the repository
